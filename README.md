# Shreya Travels | Vadodara

A modern, responsive, and SEO-optimized web application and landing page for **Shreya Travels**, a premier cab rental, outstation taxi, and car hire service based in Vadodara, Gujarat. 

Designed and developed with a focus on local SEO performance, lightning-fast loading speeds, and direct customer conversion via WhatsApp.

---

## 🚀 Features

* **Instant WhatsApp Booking:** Direct pre-filled WhatsApp inquiry forms and call-to-action buttons for seamless customer communication.
* **Transparent Pricing & Routes:** Detailed breakdown of popular one-way and return routes (Vadodara to Ahmedabad, Surat, Mumbai, Statue of Unity, etc.) and hourly local rental packages.
* **Vehicle Fleet Showcase:** Clear categories for Prime Sedans, Family SUVs (Ertiga), Luxury Innova Crysta, and Tempo Travellers.
* **Local SEO Optimized:** Embedded Local Business Schema (`JSON-LD`), geo-tagging meta tags, and structured FAQ sections tailored for local searches ("travels in Vadodara", "cab service near me").
* **Fully Responsive UI:** Built using **Tailwind CSS** with a mobile-first layout, smooth scrolling, and an interactive mobile navigation drawer.

---

## 🛠️ Tech Stack

* **HTML5** (Semantic & SEO-structured markup)
* **Tailwind CSS** (Utility-first styling via CDN)
* **Lucide Icons** (Modern lightweight iconography)
* **Google Fonts** (Plus Jakarta Sans typography)
* **GitHub Pages** (Fast, zero-cost static hosting)
